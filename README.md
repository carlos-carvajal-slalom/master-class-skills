# Master class skills

Two companion agent skills for turning study material into narrated video
lessons:

- [`master-class`](master-class/SKILL.md) develops the course map and lesson
  scripts.
- [`master-class-render`](master-class-render/SKILL.md) creates diagrams,
  narration, lesson notes, and MP4s.

## Install

Copy both skill folders into your Copilot skills directory:

```sh
cp -R master-class master-class-render ~/.copilot/skills/
```

Follow each skill's `SKILL.md` for its workflow and local dependencies.
Generated caches and virtual environments are not included in this repository.
