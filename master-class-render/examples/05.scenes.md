# Scenes · 05 · Retrying without paying twice

Each beat: one D2 diagram. `# @at "phrase"` reveals what follows when the narration reaches that phrase. `# @continue` starts from the previous beat's diagram. Classes come from `prelude.d2`.

## Beat 1
```d2
direction: right
code: Your code {class: code}
retry: "@retry\n\"for reliability\"" {class: muted}
code -> retry {style.stroke-dash: 3}
# @at "Here's what happens one afternoon"
pay: Payment system {class: tool}
code -> pay: "issue_refund(A-1005, \$220)"
# @at "the money goes out"
m1: "\$220 sent" {class: good}
pay -> m1
# @at "the response times out"
pay -> code: "TIMEOUT" {class: wrong}
# @at "the call failed"
f: "Your code sees: failed" {class: bad}
code -> f {style.stroke-dash: 3}
```
